# 🚀 Interactive Productivity Dashboard

A high-performance productivity ecosystem built to streamline engineering workflows. This project integrates multiple tools into a single interface to manage daily goals, focus, and long-term consistency.

## 🛠️ Key Functionalities

### 1. Daily Goals & Priority Batching
*   **Logic-Driven Focus**: Implements a system that limits users to 5 high-priority goals per batch to prevent burnout and ensure execution quality.
*   **Dynamic Asset Mapping**: A custom keyword-detection algorithm that automatically pairs tasks (e.g., "MERN", "Code", "Gym") with relevant high-quality visual assets.

### 2. Integrated Daily Planner & To-Do List
*   **Workflow Management**: A centralized task manager designed to bridge the gap between high-level engineering objectives and daily execution.
*   **State Persistence**: Utilizes `localStorage` to ensure all tasks and plans remain intact across browser sessions.

### 3. Pomodoro Timer
*   **Focus Optimization**: A built-in deep-work timer to manage study sessions and coding sprints effectively.
*   **UX Design**: Designed with a clean, distraction-free interface to maximize productivity during technical tasks.

### 4. Consistency Heatmap
*   **Visual Feedback**: A 7-day performance grid that updates in real-time based on achievement points earned throughout the day.
*   **Progress Tracking**: Provides an immediate visual representation of daily discipline and streaks.

### 5. Motivation Quotes Page
*   **Curated Content**: A dedicated space for inspiration to maintain momentum during intensive learning phases or placement preparation.
